# The Background Equations of Kaku's Membrane Sigma Model Are Not Integrable

Deep Bhattacharjee

The two-loop background equations R_{μν} + ¼ F_{μαβγ}F_ν^{αβγ} = 0, ∇^μF_{μνλρ} = 0 derived in M. Kaku, Phys. Rev. D 61, 085025 (2000) force F² to be constant on every solution, excluding the Duff–Stelle membrane and the Freund–Rubin vacua; the one-loop system called inconsistent there is integrable; and the two-loop sunset has a pole at d = 3 in dimensional regularization.
